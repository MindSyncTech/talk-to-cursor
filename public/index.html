How it works:
  1. Agent finishes task and calls listen() tool
  2. Script waits for TTS to finish, then starts the selected provider
  3. Your mic is monitored for speech and silence
  4. When silence is detected, the provider stops and pastes
  5. Auto-submit presses Enter, cycle repeats
The automatic loop currently requires macOS, the sounddevice Python package, and PortAudio. See the installation guide for setup commands.
Note: Environment variables (ELEVENLABS_API_KEY, ELEVENLABS_VOICE_ID) take priority over these settings. TTS changes apply to the next spoken response. Restart the Hands-Free Background Helper after changing voice-input settings.
