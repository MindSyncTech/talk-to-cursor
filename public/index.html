Cursor Voice Input Provider

For Cursor on macOS, choose Built-in for the lowest latency or Wispr Flow for the most polished dictation. If you already use FluidVoice or Handy, pick it under Other dictation apps.

Built-in: The Background Helper transcribes on-device with sherpa-onnx and types the prompt directly. The first use downloads a speech model (about 100 MB for Streaming, 480 MB for Parakeet). Paid Cloud accounts can choose Cloud dictation instead, which needs no download.
Wispr Flow: Install it from wisprflow.ai and configure its dictation shortcut below.
FluidVoice: Install the free app from fluidvoice.com (macOS 15 or later). In FluidVoice, keep the dictation shortcut in toggle mode, not press-and-hold, and enter the same shortcut below.
Handy: Install the free app from GitHub, launch it, and grant Microphone and Accessibility permissions.

How it works
  1. Agent finishes task and calls listen() tool
  2. Script waits for TTS to finish, then starts the selected provider
  3. Your mic is monitored for speech and silence
  4. When silence is detected, the transcript is typed into Cursor
  5. Auto-submit presses Enter, cycle repeats

The automatic loop currently requires macOS, the sounddevice Python package, and PortAudio. See the installation guide for setup commands.
